# Privacy Policy

**Last updated: October 12, 2026**

TransitOS does not collect, store, or transmit any personal data.

## What we collect

**Nothing.** TransitOS has no analytics, no telemetry, no advertising SDKs, and no tracking.

## Data sources

TransitOS fetches transit data (arrival times, service alerts, network shape) from a self-hosted server operated by the TransitOS project. The app's requests go to that server, which in turn reads public data from the transport operators (Metrovalencia / FGV, and others as they are added). No personal data is sent: the server keeps no per-request logs and stores nothing about you. The server is part of the TransitOS project and its source is openly available.

## Permissions

| Permission | Why |
|---|---|
| Internet | To fetch transit data from the TransitOS server |
| Location | To show your position on the map and find nearby stations |

Location data is never stored, transmitted, or shared. It is used only to display the blue dot on the map while the app is open.
